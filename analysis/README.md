# 現行設定のシミュレーション

ゲーム本体は変更せず、wallet-config.js・products.js・game.js を直接読み込みます。

macOS（Python 3・OS標準JavaScriptCore）での再実行：

```sh
python3 analysis/run-simulation.py 10000 1000
python3 analysis/summarize.py
```

- simulation-report.html：統計表とヒストグラム
- simulation-results.csv：全試行
- simulation-results.json：設定・シード・ソースハッシュを含む結果
- summary.json：集計値

支払い方針は「生存 → 会計後の空き枚数 → 上限 → 残りPT → 過払いの少なさ」の順に優先します。支払い額ごとに投入硬貨枚数が最大になる組合せを動的計画法で求め、必要な千円札を補います。紙幣無制限設定専用です。候補選択時の予測と本体の予測が一致することを各会計で確認します。

現在の1会計で有利な支払いを選ぶ方針です。残す硬貨の種類の将来価値や、将来の商品価格を先読みする完全最適化は行いません。同額・同枚数の硬貨構成の同点は探索順で決まります。人間の実プレイ成績を推定するモデルではありません。

商品順はapp.jsのランダム比較sortによるバッグ生成を再現します。sortの乱数呼び出し順はJavaScriptエンジン依存です。画面演出が消費する乱数は省略しています。ゲームオーバーになった会計も購入数・総額に含め、上限ターンに達した生存試行は打ち切りとして区別します。

保存済みの集計・CSV・HTMLは2026-09-10に現行設定で再実行した結果です。初期上限20枚・硬貨0枚・紙幣無制限、5PTごとに上限＋1枚、余剰PT繰り越し・同一会計の複数レベルアップあり、ピッタリで上限＋2枚・保有PT保持、上限が増えなかった会計は摩耗−1枚です。商品は100種類です。演出の変更は会計結果に影響しないため、演出時間はシミュレーションしません。再実行すると結果ファイルを上書きします。比較用の `comparison/` は過去の結果として保持しています。

## 小銭0枚の集計

各試行の `emptyWalletCount` は、会計確定後に財布の小銭が0枚だった会計数です。開始時の0枚や投入途中の一時的な0枚は数えません。連続して0枚だった場合は各会計を数えます。紙幣の残数には関係なく、終了会計も含めます。

HTMLレポートと `summary.json` の `empty_wallet` に、全試行での合計・平均・中央値・最大・1回以上あった試行数と割合・全会計に占める割合・1回刻みの分布を掲載します。打ち切り試行があれば観測できた会計までを含みます。購入数は5ターン刻み、購入総額は10,000円刻みを維持します。

今回の結果：小銭0枚は合計351会計、1試行あたり平均0.0351回、中央値0回、最大3回。1回以上あった試行は341件（3.41%）で、全261,644会計の約0.134%でした。試行別の回数分布は0回9,659件、1回332件、2回8件、3回1件です。

注意：保存済みレポートは小銭からっぽボーナス導入前の結果です。シミュレーション処理は新ボーナスを考慮するよう更新済みですが、結果ファイルはまだ再生成していません。

## 硬貨保持戦略との比較

[比較レポート](strategy-comparison/report.html)では、現行のからっぽボーナスを含む同一ルール・同一シード列で従来戦略と新戦略を各10,000回、最大1,000会計まで比較します。

新戦略は容量18枚以上でピッタリを最優先。不可なら紙幣と100・500円硬貨の候補から、生存を優先し、A（1・10・100円の合計枚数）：B（5・50・500円の合計枚数）が5：1に近い支払いを選びます。同点なら額面の種類数、投入硬貨の少なさ、過払いの少なさで選びます。18枚未満は従来戦略です。詳細な探索範囲はレポートを参照してください。

```sh
python3 analysis/run-strategy-comparison.py 10000 1000
python3 analysis/report-strategy-comparison.py
```

比較結果は `strategy-comparison/` に分離し、従来の保存済み単一戦略レポートは保持します。打ち切り生存者を終了扱いせず、観測平均と終了者のみの平均を分けて表示します。

上限突破（50枚到達で20枚・小銭0枚へ戻す）をシミュレーション処理に反映しました。保存済みの単一戦略レポートはこの変更前の結果です。比較レポートは上限突破を含む現行仕様で再実行しています。再実行時はカード枚数も試行データに記録します。

比較レポートは各10,000回・最大1,000会計で上限突破リセットを反映して再生成しました。カード獲得分布、初回突破から2回目への到達割合、最後のリセット後の終了までの会計数を掲載しています。導入前の比較結果は `strategy-comparison/before-breakthrough/` に保存しています。

現行仕様での硬貨保持戦略の結果：全10,000試行が終了（最大184会計）、平均19.44会計・22,291円。カード分布は0枚9,811件、1枚178件、2枚10件、3枚1件。初回突破者189件のうち11件（5.82%）が2回目に到達しました。最後のリセットから終了までは平均8.68会計でした。導入前に1,000会計まで生存した184件に対し、今回は打ち切り生存者0件です。有限試行であるため、あらゆる戦略での終了を保証するものではありません。
