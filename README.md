# ピッタリ小銭パズル

Specifications.md に基づいたブラウザゲームです。ビルドやパッケージのインストールは不要です。

## 起動

`index.html` を Chrome / Safari などで開いてください。または、このフォルダで以下を実行し、http://localhost:8000 を開きます。

```sh
python3 -m http.server 8000
```

## 財布の初期設定を変更する

[wallet-config.js](wallet-config.js) を編集して保存し、ブラウザを再読み込みしてください。ゲーム中の財布は引き継がず、新しい設定で開始します。「もう一度お買いもの」も読み込み済みの設定で初期化します。

```js
globalThis.WALLET_CONFIG = {
  coins: { 500: 0, 100: 2, 50: 1, 10: 2, 5: 1, 1: 2 },
  notes: { 1000: 5, 10000: 1 },
  maxCoinsCapacity: 15,
};
```

- `coins`：各硬貨の初期枚数。すべて0以上の整数で指定します。
- `notes`：千円札・一万円札の初期枚数。`null`（引用符なし）で無制限、`0`で所持なしです。初期設定は両方とも無制限です。
- `maxCoinsCapacity`：硬貨枚数の上限。1以上の整数で、初期硬貨の合計枚数以上を指定します。紙幣は上限に含みません。完済時の拡張は＋2枚です。

指定された6種類の硬貨・2種類の紙幣のキーは削除せず、数値だけを変更してください。不正な値は画面に設定エラーを表示します。設定ファイルは直接HTMLを開く場合にも読み込めるJavaScript形式です。

有限の紙幣は投入すると減り、トレイから返すと戻ります。お釣りの紙幣も額面別に加算され、残り0枚の紙幣は選択できません。有限設定で資金が足りなくなった場合はページを再読み込みして初期状態に戻せます。

## 遊び方

- 小銭をタップ・上スワイプ、お札をタップして支払いトレイに投入。
- トレイ内のお金をタップすると1枚返却。「全返却」で投入を取り消せます。
- 価格以上を投入して「お会計」。お釣りは千円単位を紙幣で返し、1,000円未満の端数を最少枚数の硬貨で返します。紙幣は財布の小銭枚数に含めません。有限設定では紙幣の所持枚数に加算します。
- 支払い後の小銭が0枚なら容量が2枚増加。容量を超えるとゲームオーバー。
- 「♪ OFF」で効果音をオンにできます。最高購入額はブラウザに保存します。

## 仕様の補足

初期財布は100円×2、50円×1、10円×2、5円×1、1円×2（計8枚・277円）、初期容量は15枚です（完済で17→19→…）。最初の商品はアイス、その後は6商品を一巡ごとに並べ替えて出品します。価格は初回・再開時を含め毎回リスクレベルに応じて生成します。容量アップ後も次の商品に進みます。戦利品は重力・バウンドのCSSアニメーションで、直近16点を表示します。結果のレシートには全購入品を掲載します。

画像は絵文字による仮イラストです。表示は端末によって異なります。Google Fonts が使えない場合もシステムフォントで動作します。ゲームデータは再読み込みでリセットされ、最高額のみ保持します。

## 検証

`tests/test.html` をブラウザで開くと、お釣りの最少枚数（1〜10,000円を動的計画法と照合）、返却、支払不足、容量アップ、容量境界、ゲームオーバー、リスク確率の切替境界、生成価格とリスクの一致、増減予測と実際の支払い結果、画面操作を30テストで検証します。

- `game.js`: 描画から独立したゲームルール
- `app.js`: 操作、描画、サウンド、演出
- `style.css`: PC / スマホ向けレイアウト

## 難易度と価格生成

購入完了数0〜2（1〜3品目）はレベル1〜5を60/30/10/0/0%、3〜9（4〜10品目）は10/30/40/20/0%、10以上（11品目〜）は5/15/30/35/15%で抽選します。

リスクは千円札だけで払える最小必要額 `ceil(価格 / 1000) × 1000` に対するお釣り枚数で決めます。0〜3枚 / 4〜6枚 / 7〜9枚 / 10〜12枚 / 13〜15枚が各レベルです。元の商品価格の千円単位部分を保ち、選択したレベルに合う1〜1,000円の端数候補から等確率で価格を生成します。購入済み商品の価格は固定です。

例示価格より枚数の定義を優先しています。999円は1枚でレベル1、1円は15枚でレベル5です。紙幣で返す分を除くため、お釣りの硬貨は最大15枚です。初期容量15枚でも、手持ちとお釣りの合計が上限を超えるとパンクします。

支払いプレビューの増減は「お釣りの硬貨枚数 − トレイに投入した硬貨枚数」。投入前の財布を基準に、確定後の枚数と容量も表示します。金額不足・全返却・確定後は増減を表示しません。

例：9,030円に10,050円を出すと、お釣りは1,020円（紙幣1,000円＋10円玉2枚）。50円玉を1枚出しているため、小銭の純増は＋1枚です。

トレイのお金は1枚ずつ表示し、タップした1枚を返却します。お会計後、お釣りの紙幣（一万円札・千円札）と硬貨がトレイに並び、財布の各額面の位置へ移動します。受け取り後に枚数表示・容量アップ・パンク演出を更新し、演出中は支払い操作を停止します。端末の「視差効果を減らす」設定では移動を短いフェードに置き換えます。
