# イラスト素材

参考画像の温かい店内・緑のエプロン・金属と革の質感を元にimagegenで新規生成。Web用JPEGへ変換し、すべてプロジェクト内から読み込みます。

- `shop.jpg`：1536×1024。店員を左、商品吹き出し用の余白を右に配置。商品名・価格はHTML表示。
- `coins.jpg`：1536×1024。上段500・100・50円、下段10・5・1円。`theme.css`で各硬貨の範囲を表示し、財布・トレイ・お釣り・終了演出で共用。
- `notes.jpg`：1536×1024。上から1000・5000・10000円の架空紙幣。財布・トレイ・お釣りで共用。

財布、ステッチ、ゴールドカード、ボタンはCSSで描画し、画面幅に合わせて伸縮します。画像内の文字にはゲーム状態を持たせず、価格・所持枚数・ボタンの読み上げ情報は既存のDOMを使用します。

- `tray.jpg`：生成した金属製キャッシュトレイ。金属面と縁は画像で表示し、上に操作可能なお金を配置します。

紙幣収納は一続きのポケットです。各紙幣は約2.05：1の横長形状とし、額面は左下・所持枚数は右上に、背景のない白抜きのHTML文字として重ねます。

- `cashier-idle.jpg`：元画像の顔だけを編集した待機表情。CSSマスクで顔の内側のみを合成し、髪・体・背景は元画像を維持。笑顔は `shop.jpg` の元の顔を使用。
- `counter.jpg`：店員の手前・トレイ周囲・財布の丸角の外側を一枚で覆う共通木目。トレイ画像は輪郭でクリップし、画像に含まれる周辺木目を隠す。

トレイ表示領域は幅360px基準で高さ112px（元画像3：1の比率）に固定。50・5円硬貨はCSS透明マスクで穴を抜き、財布・トレイ・飛散で共用します。

## 3DCG版の店員・背景

現在の表示は `shop-3d.png`（店内＋笑顔の店員）と `cashier-idle-3d.png`（待機表情）を使用します。どちらも1536×1024。温かい3DCGアニメーション映画風で、丸い頬、大きな目、そばかすのあるオリジナル店員です。既存と同じ構図・顔の位置を維持し、待機表情は従来のCSSマスクで重ねます。

組み込み画像生成ツールで作成。生成プロンプトは `prompts-3d.md` に保存しています。旧JPEGは比較・復元用に保持し、画面からは参照しません。

## 採用版：スタイライズ強化

現在のゲーム表示は `shop-stylized.png`（通常表情の店員＋店内）と `cashier-stylized-smile.png`（会計成立時の笑顔）です。両方1536×1024。候補 `shop-3d-stylized-candidate.png` を通常表情として採用しました。大きな頭・小さな肩と胴体の構図に合わせ、顔マスクは中心28％・34％、横半径13％・縦半径20％へ変更しています。背景や体は常に通常画像を使用し、顔の差分だけを重ねます。

組み込みimage_genで笑顔差分を作成。プロンプトは `prompts-stylized-smile.md` に保存。前述の3DCG版および旧JPEGは旧素材です。
